# ARC Lite — проверка 16 октября 2026

## Подтверждено на Windows Asus

- На Asus установлена локальная версия **arc-lite@home-ai-local 0.3.2**. Для Codex она запускается как Python stdio MCP, без VDS, публичного порта, Docker, облачного туннеля и отдельных ключей MCP.
- На локальном рабочем экземпляре ARC Lite прошли **35 unit-тестов**.
- Из **модели Codex** (не напрямую из тестового Python-скрипта) подтверждены: вызов ARC Lite CLI `status` с результатом `hostname=Asus`; создание разрешённого тестового файла через `write --confirm` и чтение через `cat`. Созданный тестовый файл удалён после проверки.
- CLI `--help` обновлён: у инструмента есть действия `status, windows, processes, screenshot, app, ps, ls, cat, write, tool`. Старое слово `files` было ошибкой в справке.
- Модель Codex обнаружила штатный `cua_repl/js` Computer Use, но при попытке запустить Windows Calculator из неинтерактивного `codex exec` получила **`Trusted RPC service is not configured: sky`**. Пуск GUI из sandbox PowerShell не является поддерживаемой заменой: PID не доказывает появление окна у пользователя.

## Правильный способ использования

- Файлы, диагностика, процессы, ограниченный PowerShell: локальные MCP инструменты в поддерживаемой сессии; если они недоступны модели, использовать `arc-lite-control` skill и локальный CLI `arc_cli.py`.
- Видимые Windows-приложения, окно, мышь и клавиатура: только **интерактивная локальная сессия ChatGPT Desktop / Codex** с работающим штатным Computer Use (`@oai/sky`), разрешениями пользователя и актуальной проверкой окна.
- Обычный веб-чат и `codex exec` без доверенной Computer Use службы **не гарантируют** возможность управления настоящим GUI, хотя локальный stdio агент работает.
- Не обходить sandbox, защиту Windows или подтверждения. Опасные команды, запись/удаление данных и чувствительный ввод выполняются только с необходимым разрешением владельца.

## Приёмочные проверки, которые ещё нужны

1. ChatGPT Desktop → интерактивный локальный Work/Codex → выбрать плагин ARC Lite.
2. Запросить статус Asus; убедиться, что инструмент действительно исполнен моделью.
3. Через штатный Computer Use открыть Калькулятор и **подтвердить видимое окно**. Не засчитывать только PID.
4. После перезапуска ChatGPT Desktop проверить повторное подключение без ручной переустановки.
5. Только после этого считать полноценное управление интерфейсом завершённым и рассматривать отказ от Desktop Commander.
