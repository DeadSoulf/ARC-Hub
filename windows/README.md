## Удаление устройства и повторное подключение

В ARC Web под владельцем `owner` откройте **Компьютеры**, выберите
нужный ПК и нажмите **«Удалить устройство»**. Для безопасности
потребуется ввести точное имя устройства и ещё раз подтвердить действие.

Удаление **отзывает секрет устройства на сервере**, очищает все
права пользователей для данного ПК, состояние соединения и сеанс.
Оно **не удаляет файлы на Windows-компьютере** и не удаляет сам ARC Agent.
Пока устройство выполняет операцию или находится под активным
управлением, удаление блокируется.

Чтобы повторно зарегистрировать тот же компьютер: удалите его
в ARC Web, откройте новый `ARC-Agent-Setup.exe` на соответствующем
ПК, выберите **«Сбросить локальную привязку ARC Hub»**, затем
в ARC Web создайте **новый одноразовый код** и подключитесь.
Device ID и локальные разрешения будут сохранены.
Неправильный или просроченный код возвращает объяснение,
а уже зарегистрированный ID — отдельную ошибку `409`.

Важно: если агент ранее был зарегистрирован на другом ARC Hub,
отзыв ключа на старом сервере требуется сделать отдельно.
Локальный сброс не удаляет действующую регистрацию на сервере.

## Подключение через копирование кода

Войдите в ARC Web и нажмите **Компьютеры → Подключить ПК → Копировать код**.
В ARC Agent нажмите **Подключить по одноразовому коду**, затем
**Вставить код**. Работает также `Ctrl+V`, `Shift+Insert` и
контекстное меню правой кнопки мыши. Windows-клиент читает буфер
обмена **только по вашему действию**, проверяет 12 символов и
автоматически форматирует их через дефисы.

Если увидели `HTTP 503`, скорее всего, VDS ещё работает со старым
`arc-hub.service`; выполните указанный выше скрипт обновления сервера.
При ошибке обновления пришлите системный журнал без секретов.
Новый код нужен, если ARC Hub перезапускался: коды хранятся в памяти
и действуют не более 10 минут.

## Подключение компьютера по одноразовому коду

Теперь **без SCP и JSON-файлов**:

1. Администратор `owner` открывает **ARC Web → Компьютеры → Подключить ПК** и получает код вида `ABCD-EFGH-JKLM`.
2. На Windows установите `ARC-Agent-Setup.exe`, нажмите **«Подключить по одноразовому коду»**.
3. Укажите `https://vpn.homeaicore.ru` и код, нажмите **«Подключить компьютер»**.
4. ARC Hub регистрирует новый Device ID, создаёт отдельный секрет устройства и выдаёт владельцу только `status` и `inspect`. Агент начинает связываться с сервером по HTTPS.

Код действует 10 минут, только на один новый ПК, после использования недействителен. Доступ к созданию кода есть только у `owner`. Регистрация не заменяет секреты уже зарегистрированных устройств. Для экрана, файлов, PowerShell и управления нужны отдельные разрешения владельца.

Старый способ `enroll.ps1` / JSON остаётся резервным. Код исчезает при перезапуске ARC Hub — в таком случае просто создайте новый. Код не является паролем владельца и его нельзя публиковать.

# ARC Agent 0.2 (Windows)

Standalone Windows per-user background agent, no visible PowerShell after installation.

Requirements: Windows 10/11, Python 3.11+ with pythonw.exe, outbound HTTPS to VDS ARC Hub.

Run install.cmd from an extracted ZIP. Local defaults are read-only and use port 8876, so if previous ARC Fleet pilot already owns 8876 this installer registers but **does not start** the new agent. The old working ARC 0.1 connection on Asus is left intact. For a side-by-side test run `install.cmd -Port 8896` on a machine without a prior 0.2 installation, and do not stop port 8766.

Creates %LOCALAPPDATA%\ARC\bin and %LOCALAPPDATA%\ARC\agent.json, an "ARC Agent" Scheduled Task, login + periodic restarts. Task runs pythonw.exe and a supervisor that monitors a local read-only HTTP MCP server and an outbound gateway worker; logs are rotated in %LOCALAPPDATA%\ARC\logs.

Admin enrollment is generated by ARC Hub with `arc_admin.py add-device`. Transfer the JSON through a secure path to the right PC and apply:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\enroll.ps1 -File C:\SecureTransfer\pc-enroll.json

Do not share or publish enrollment JSON. Remove transfer copies after applying.

Default local grants include only status and process/window inspection. To enable screen, files, apps, shell or input, configure opt-in `permissions` in agent.json and repeat corresponding explicit grants for the user and device in VDS registry. Changes will restart the owned child agent and worker. A system administrator can stop/uninstall; this is not intended to resist legitimate administrator control.

Interactive desktop control works only in an unlocked logged-in user session. A true system service, native signed EXE/MSI and OAuth provider are future production tasks.

## ARC Agent одним исполняемым файлом

Скачайте **ARC-Agent-Setup.exe** из раздела Releases GitHub или кнопкой
«Скачать клиент .exe» в ARC Web. Это один файл с встроенным Python,
не ZIP с исходниками. Откройте его на Windows и нажмите
«Установить / обновить». Приложение установится в
`%LOCALAPPDATA%\ARC\ARC-Agent.exe` и зарегистрирует задачу
`ARC Agent` для фонового запуска при входе в Windows.

Клиент сохраняет существующий `agent.json`, данные регистрации и
разрешённые каталоги. Для подключения к VDS требуется индивидуальный
`device_id` и enrolment JSON, выданный владельцем Hub по
защищённому каналу. Учётные данные **не входят в exe**.

Это неподписанный preview; Windows SmartScreen может предупредить.
Проверяйте SHA256 из одноимённого файла в Releases.
Первое включение удалённого экрана, управления и PowerShell требует
явного разрешения владельца компьютера и индивидуальных прав пользователя.

**Внимание:** обновление установленного EXE выполняется только с
проверенным источником. В production потребуются code signing,
подписанные обновления, тестирование отката и GUI регистрации устройства.

### Регистрация без PowerShell

После установки откройте тот же `ARC-Agent-Setup.exe` и нажмите
**«Подключить к ARC Hub (файл регистрации)»**. Выберите персональный
enrollment JSON, полученный от администратора ARC Hub по защищённому каналу.
EXE проверяет ID компьютера, обязательный HTTPS и права доступа к файлу
конфигурации. Чужой идентификатор или попытка незаметно заменить ключ
отклоняются. Переданный JSON после успешного подключения удалите из
временной папки.

Для командной строки существует `ARC-Agent-Setup.exe --enroll путь\к\файлу.json`.
Отдельно устанавливать Python или запускать `.ps1` больше не требуется.
